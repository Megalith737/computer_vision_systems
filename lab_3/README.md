## Мета

Реалізувати детектор кутів Гарріса власноруч, порівняти його з SIFT і ORB та

масштаб, яскравість, шум, розмиття, контраст).

## Як запустити

З кореня репозиторію (Windows):

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
cd lab_3
python src\prepare_frames.py
python src\01_harris_vs_cv2.py
python src\02_harris_scale.py
python src\03_sift_orb.py
python src\04_repeatability.py
python src\04_repeatability.py --series blur contrast
python src\05_plots.py
```

Linux / macOS: замість активації `source .venv/bin/activate`, шляхи через `/`.
Потрібен Python 3.10 або новіший. Скрипти запускаються з кореня `lab_3/`:
шляхи вираховуються від теки `lab_3`, а не від поточної директорії.

`prepare_frames.py` читає `data/raw/`, зменшує кадри до 1600 px по довшій
стороні й пише сірі копії в `data/prepared/gray/`. Після його запуску в
`data/prepared/gray/` треба залишити лише 8 відібраних кадрів (решту PNG
видалити): скрипти `01`-`05` беруть усі PNG цієї теки.

`04_repeatability.py` дописує `results/repeatability.csv` рядок за рядком:
його можна перервати й запустити знову, готові рядки пропускаються. Для
швидкої перевірки: `--max-images 1`. Повний прогін чотирьох основних серій на
8 кадрах займає кілька хвилин.

Версії бібліотек можна переглянути й записати у `requirements.txt`:

```
python tools\print_versions.py            # показати
python tools\print_versions.py --write    # записати requirements.txt
```

(`n_p1_vis`, `n_p2`) потрібна для інтерпретації: на зменшеному кадрі Гарріс
може знайти менше за N точок.

## Параметри алгоритмів

- Випадковий стан: `np.random.seed(42)` і `SEED = 42` у `common.py`; шум у
  частині D генерується від `SEED + номер кадру`.
- Гарріс: Sobel 3×3, гаусіан σ = 1.5 на добутках градієнтів (спочатку добутки,
  потім згладжування), k = 0.04, поріг R > 0.01·max(R), власне NMS з радіусом
  10 px.
- Умова чесного порівняння: для Гарріса, SIFT і ORB лишається N = 500
  найкращих точок за response; один допуск ε = 3 px; детектори бачать лише
  внутрішню частину кадру (відступ 15 px від межі видимої області).
- Частина A: збіг у межах 2 px; контроль -- те саме з рівним вікном 5×5 як у
  `cv2.cornerHarris` (`blockSize=5`).
- Частина B: зменшення вдвічі (`INTER_AREA`), перенесення x = 2x' + 0.5.
- Повторюваність: частка точок оригіналу, перенесених матрицею H і
  таких, що мають відповідник у ε = 3 px, відносно min(|P₁|, |P₂|), де P₁ --
  точки оригіналу, що потрапили у видиму область.
- Сітка перетворень: поворот 0-90° (крок 10°) навколо центру; масштаб
  0.5-2.0 (крок 0.25, `INTER_AREA` при зменшенні й `INTER_LINEAR` при
  збільшенні, матриця H узгоджена з центрами пікселів); множник яскравості
  0.5-1.5 (крок 0.1, з відсіканням до 0-255); гауссів шум σ = 0, 5, 10, 15, 20;
  додатково розмиття σ = 0-4 px і множник контрасту відносно середньої
  яскравості 0.5-1.5.
- Контроль: «нульове» перетворення (0°, ×1.0, шум 0) дає 100 %; скрипт
  попереджає, якщо це не так.
