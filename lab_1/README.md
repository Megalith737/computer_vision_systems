## Як запустити

З кореня репозиторію (Windows):

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
cd lab01\src
python lab01.py
```

Linux / macOS: замість активації `source .venv/bin/activate`.

Потрібен Python 3.10 або новіший. Скрипт читає файли з `lab01/data/`; якщо
якогось файлу немає, він зупиняється з повідомленням `Немає файлу data/...`.

## Які файли отримаються

Теки `results/` і `figures/` створюються автоматично.

| Файл | Що містить |
| --- | --- |
| `results/step4_compression.csv` | формат, якість, розмір файлу (КБ), PSNR (дБ) |
| `results/step5_exif.csv` | фокусна відстань, витримка, ISO |
| `results/part_b_color_spaces.csv` | межі порогів, accuracy та IoU для RGB і HSV на двох кадрах |
| `results/step13_interpolation.csv` | PSNR чотирьох методів інтерполяції |
| `figures/step2_bgr_rgb.png` | порядок каналів BGR і RGB |
| `figures/step3_overflow.png` | переповнення `uint8` |
| `figures/step4_psnr_vs_size.png` | PSNR залежно від розміру JPEG (логарифмічна вісь) |
| `figures/step12_aliasing.png` | зменшення без згладжування і зі згладжуванням |
| `figures/step13_interpolation.png` | збільшення фрагмента чотирма методами |
| `figures/step14_gamma_images.png` | зображення після гамма-корекції |
| `figures/step14_gamma_curves.png` | передавальні характеристики |

У консоль виводяться числа, яких немає в CSV: властивості масиву (крок 1),
кількість пікселів із переповненням (крок 3) та приклад усереднення для
гамма-кодування (крок 14). Їх треба перенести у звіт.
Файли `results/tmp/` тимчасові (їх створює крок 4) і в репозиторій не йдуть.

## Параметри алгоритмів

- Випадковий стан: `np.random.seed(42)` (у цій роботі випадковості немає).
- Крок 3: додається 50 до значень пікселів.
- Крок 4: якість JPEG 95, 75, 50, 25, 10; PNG без втрат.
- Частина B: межі порогів -- 1-й і 99-й перцентилі значень усередині маски на
  кадрі 1; на кадрі 2 застосовуються без змін.
- Крок 12: зменшення в 4 рази, гаусове згладжування з σ = 2.
- Крок 13: фрагмент 256×256 зменшується в 8 разів (`INTER_AREA`) і
  збільшується назад.
- Крок 14: γ = 0.5, 1.0, 2.2.
